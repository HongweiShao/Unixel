Unixel
DICOM Medical Imaging
for Technicians & Engineers

A fast, cross-platform desktop tool to view, process, and export DICOM datasets — with built-in de-identification and traceable tool metadata.

Download for Windows View on GitHub
v0.1.0•Tauri 2 · Vue 3 · Rust•LGPL-3.0
Capabilities
Everything you need for DICOM workflows
🔍

DICOM Viewer

Interactive window/level (brightness & contrast) adjustment and frame navigation for fast image review.

📤

Export & Batch Convert

Single-frame or full-series export with selectable transfer syntaxes and per-export scope control.

🔒

De-identification

Anonymization using PBKDF2-derived keys and AES-256-GCM encryption of private metadata tags.

🏷️

Tool Identification

Writes a traceable tool block into exported DICOM — application, version, operator, and local date/time.

📚

In-app Manual

Full user manual accessible from the Help menu — no external PDF viewer required.

⚡

Native & Lightweight

Built on Tauri 2 with a Rust core (dicom-rs) for a small footprint and native performance.
